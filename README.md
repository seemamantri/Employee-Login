# Login System (ASP.NET + ADO.NET + SQL Server)

This project is a simple **ASP.NET Web Forms Login System** developed using **ADO.NET** and **SQL Server**.  
It verifies registered users by checking their **Email** and **Phone number** using a **Stored Procedure**.

---

## 🚀 Features

- User Login form with Email and Phone fields.  
- Input validation to ensure both fields are filled.  
- Authentication through stored procedure (`sp_LoginCheck`).  
- Displays success message if details match the database.  
- Redirects user to the Home page upon successful login.
